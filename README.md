# タブURLをNotionに貼り付け（Brave拡張機能）

YouTubeの「登録チャンネル」タブ（`https://www.youtube.com/feed/subscriptions`）より右側に開いているタブのURLを、Notionの指定ページに自動で貼り付けます。

- 設定したチャンネル名（を含む）のタブ → ページ上部のコードブロック（プレーンテキスト）に、既存URLの下に上から順に追記。追記後、一番下のURLの下には3行以上の空行を確保
- それ以外のタブ → 既存のブックマーク一覧の一番上に挿入。同時に複数追加する場合は、右側のタブほど上に来る（タブの並びが逆転する）。テキストボックスと一番上のブックマークの間の空行はそのまま維持される

## 1. Notion Integrationを作成する

1. https://www.notion.so/my-integrations を開く
2. 「+ 新しいインテグレーション」から作成（名前は何でもOK、ワークスペースを選択）
3. 作成後に表示される「Internal Integration Secret」をコピーしておく（`ntn_...` から始まる文字列）

## 2. Notionページをインテグレーションと共有する

1. 貼り付け先のNotionページ（例: 「ブックマーク」ページ）を開く
2. 右上の「•••」メニュー →「コネクト」→ 手順1で作成したインテグレーションを選択して接続
   - これを忘れるとAPI経由での書き込みができません

## 3. 拡張機能をBraveに読み込む

1. Braveで `brave://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダ（`manifest.json`があるフォルダ）を選択

## 4. 拡張機能の設定をする

1. `brave://extensions` の拡張機能カードから「詳細」→「拡張機能のオプション」を開く
   （またはツールバーの拡張機能アイコンを右クリック →「オプション」）
2. 以下を入力して保存
   - **Notion Integration Secret**: 手順1でコピーしたシークレット
   - **貼り付け先NotionページのURL**: 手順2で共有したページのURL
   - **「指定したチャンネル」欄**
     - **テキストで貼り付けるチャンネル名**: URLをテキストとして貼りたいチャンネル名を1行ずつ
     - **貼り付け後にタブを閉じる**: テキストとして貼り付けたタブを閉じるかどうか
   - **「指定していないチャンネル」欄**
     - **指定していないチャンネルはブックマークとして貼り付ける**: OFFにすると、指定していないチャンネルのタブは無視されます（Notionに保存されず、閉じられもしません）。Notion API経由で作成するブックマークにはサムネイル画像は表示されません
     - **YouTube以外のサイトのタブもブックマークとして保存する**: OFFにするとYouTube以外のタブは無視されます（Notionに保存されず、閉じられもしません）
     - **貼り付け後にタブを閉じる**: ブックマークとして貼り付けたタブを閉じるかどうか（テキスト側とは独立して設定可能）

## 使い方

1. ブラウザで `https://www.youtube.com/feed/subscriptions`（登録チャンネル一覧）のタブを1つ開く
2. そのタブより右側に、Notionに送りたいタブを並べて開く
3. ツールバーの拡張機能アイコンをクリック
4. 処理が完了すると通知が表示され、（設定していれば）対象タブが閉じます

## 注意点

- 起点タブより右側の、`http`/`https`のタブのみが処理対象です（起点タブ自身は含みません）
- チャンネル名はYouTubeのoEmbed公開APIから取得しています（タブタイトルではなく動画URLから直接取得）
- チャンネル名の一致判定は完全一致ではなく、設定したチャンネル名がタブのチャンネル名に「含まれていれば」一致とみなします（大文字小文字は区別しません）
- 複数ウィンドウを開いている場合は、拡張機能アイコンをクリックした時にアクティブな（フォーカスのある）ウィンドウのタブのみが処理対象です
